    Glossary

    Capability
    A step type a worker says it can run, such as export.v2/render. The dispatcher only sends a step to workers that list a matching capability.
    worker-3 lists 14 capabilities when healthy.
    Dispatcher
    The scheduler component that picks a worker for each queued step, from the workers the registry lists as eligible.
    handleConnect
    The scheduler function that runs when a worker connects. It either resumes the worker's existing session or creates a new one.
